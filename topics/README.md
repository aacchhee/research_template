# Topic records

One topic is one working branch and one PR. Use [TOPIC_LOG.md](../templates/TOPIC_LOG.md), the stage rules in [WORKFLOW.md](../agents/WORKFLOW.md), and a descriptive topic slug.

Keep proposals, gate decisions, reports, audit-NN.md, response-NN.md, numbered `handoffs/NN-<step>.md` files and reproducible checks here. Use [HANDOFF.md](../templates/HANDOFF.md) for complete next-step instructions; keep earlier handoff bodies unchanged. Put mathematical results in durable track theory files immediately; link them from the topic log. Preserve every generated candidate and each scoped rejection.

## Scaffold maintenance

These records concern the reusable template, not an inherited scientific campaign. Omit or archive template-maintenance topics when starting a new research repository.
